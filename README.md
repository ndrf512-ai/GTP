# Пивной Угон: гориллы на диванах

Аркада с видом сверху в духе старых криминальных песочниц. Герой в чёрной шапке
и чёрном пуховике с белыми полосками ходит по осеннему району с жёлтыми
хрущёвками, грабит пивные, пьёт пиво, угоняет тачки и уходит от полиции.
Полиция здесь — гориллы в фуражках, которые гоняют на диванах с мигалками.

## Установка на Android

1. Скачай [`release/PivnoyUgon.apk`](release/PivnoyUgon.apk) на телефон.
2. Открой файл. Если Android спросит, разреши установку из этого источника
   (браузер или файловый менеджер → «Разрешить установку неизвестных приложений»).
3. Запусти «Пивной Угон». Игра работает без интернета.

Нужен Android 7.0 или новее. Игра идёт в горизонтальной ориентации.

Можно играть и в браузере: открой `game/index.html`, управление с клавиатуры.

## Управление

| Телефон | Клавиатура | Что делает |
|---|---|---|
| Джойстик слева | WASD / стрелки | Ходить; в машине — куда ехать |
| 👊 БИТЬ | Пробел | Удар (по прохожим, машинам и диванам) |
| 🛑 ТОРМОЗ | Пробел в машине | Ручник, занос |
| 🍺 ПИТЬ | Q | Выпить пиво |
| 🚗 ТАЧКА | E | Сесть в машину / выйти |
| 💰 ГРАБИТЬ | R | Ограбить пивную (стоять у двери 3 секунды) |
| 🛒 50 ₽ | B | Купить пиво |
| ⏸ / «Назад» | P / Esc | Пауза |

## Как играть

- **Пиво** лечит (+22 здоровья) и поднимает «градус». С 3 градусов включается
  **пивная сила**: удары в 2,5 раза сильнее, урон по тебе меньше. С 4 градусов
  начинает штормить, а на 7 герой вырубается. Градус постепенно спадает.
- **За руль только трезвым**: с градусом 3 и выше в машину не пустят, а в машине
  пить нельзя.
- **Пивные** (жёлтые точки на мини-карте): купить пиво за 50 ₽ или ограбить.
  После ограбления пивная закрыта «на переучёт» на 100 секунд.
- **Розыск** — до пяти голов горилл. Чем больше голов, тем больше диванов
  и тем они быстрее. С трёх голов гориллы кидаются бананами, а на кожуре
  поскальзываются все, включая машины.
- **Как сбросить розыск**: спрятаться, чтобы гориллы потеряли тебя из виду,
  разломать диваны кулаками или тачкой (из диванов выпадает мелочь),
  или проехать через автомойку «Мойдодыр» за 150 ₽.
- Если гориллы прижмут тебя и постоят рядом — **ПОВЯЗАЛИ**: отберут всё пиво
  и 30 % денег, выпустят из «Обезьянника». Кончилось здоровье — **ПОТРАЧЕНО**,
  проснёшься у травмпункта.
- Задания приходят по СМС от Палыча: купить и выпить пиво, ограбить пивную,
  отнести пиво друзьям на лавочки, разломать диваны, успеть на остановку.

## Сборка APK

```bash
python3 tools/build_apk.py
```

Нужны Python 3 и JDK 11+. Android SDK не нужен: скрипт сам скачивает с Maven
Central классы Android API 34 (Robolectric `android-all`), `dx` и `apksig`,
генерирует бинарные `AndroidManifest.xml` и `resources.arsc`, компилирует
`android/src/.../MainActivity.java` (полноэкранный WebView) и подписывает APK
схемой v2 ключом `android/debug.keystore` (пароль `android`). Это отладочный
ключ: с ним обновления ставятся поверх старой версии, но для публикации
в магазине нужен свой ключ.

## Структура

- `game/index.html` — вся игра: canvas, звук на WebAudio, без внешних файлов.
- `android/` — Activity с WebView, иконка, ключ подписи.
- `tools/build_apk.py`, `tools/SignApk.java` — сборка и подпись.
- `release/PivnoyUgon.apk` — готовый APK.
